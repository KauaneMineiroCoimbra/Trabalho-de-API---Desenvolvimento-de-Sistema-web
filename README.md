Projeto Dados Pessoais – Etapas 00 a 07 (Individual)

Neste repositório está o desenvolvimento do projeto Dados Pessoais, realizado durante as atividades da disciplina de Desenvolvimento Web.

O projeto foi desenvolvido utilizando Java e Spring Boot, passando por diferentes etapas, desde a criação da API até a implementação de recursos de segurança e autenticação.

O que foi desenvolvido em cada etapa

Etapa 00 – Configuração inicial

Criação e configuração do projeto.

Organização da estrutura de pastas e pacotes.

Configuração das dependências e do ambiente de desenvolvimento.

Etapa 01 – Criação da API REST

Desenvolvimento dos primeiros endpoints.

Implementação do controller e da camada de serviço.

Criação da consulta de pessoas utilizando GET.

Organização dos dados por meio de DTOs.

Etapa 02 – Cadastro e validações

Implementação do cadastro de pessoas utilizando POST.

Aplicação de validações nos campos.

Criação de validação personalizada para verificar se as senhas são iguais.

Tratamento de dados inválidos.

Etapa 03 – Integração com páginas HTML

Desenvolvimento das páginas de interface.

Integração entre HTML, JavaScript e a API utilizando Fetch.

Implementação das operações de cadastro, consulta, alteração e exclusão de pessoas.

Etapa 04 – Persistência com banco de dados

Implementação do JPA e Hibernate.

Configuração do banco de dados H2.

Criação das entidades e dos repositórios.

Implementação da persistência dos dados.

Etapa 05 – Organização da camada de serviço

Criação da interface de serviço.

Separação das implementações utilizando Map e JPA.

Organização da lógica de negócio para facilitar a manutenção e a evolução do projeto.

Etapa 06 – Segurança e autenticação

Implementação do Spring Security.

Configuração das regras de acesso aos endpoints.

Criação do mecanismo de autenticação.

Implementação de usuários e permissões.

Etapa 07 – Autenticação com JWT

Implementação da autenticação utilizando JWT.

Criação do serviço responsável pela geração e validação dos tokens.

Implementação do filtro de autenticação.

Utilização de BCrypt para criptografia das senhas.

Aplicação de regras de autorização por perfil de usuário.

Considerações finais

O desenvolvimento dessas etapas permitiu colocar em prática conceitos importantes de Desenvolvimento Web, Java, Spring Boot, APIs REST, banco de dados, validações e segurança.

O projeto foi construído de forma progressiva, acompanhando os conteúdos trabalhados durante a disciplina e buscando aplicar os conhecimentos adquiridos em cada etapa.
